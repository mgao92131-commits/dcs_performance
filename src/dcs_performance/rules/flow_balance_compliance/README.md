# 浆料进料量平衡考核

本规则直接使用DCS已经修正后的 `LOGIC27/YK-TLFH/OUT1.CV`，不再进行 `÷1.0099`。

计算方式：

```text
LOGIC27流量 = LOGIC27的60秒尾随滑动平均
SY总流量 = 60秒尾随滑动平均(SY-116 + SY-216)
流量偏差 = LOGIC27流量 - SY总流量
```

判定标准：

- `-15 ≤ 流量偏差 ≤ +15`：合格；
- 流量偏差小于 `-15` 或大于 `+15`，并连续达到300秒：生成一次考核事件；
- 每个连续超限区间只生成一次事件。
- 每次确认的 `flow_low` 或 `flow_high` 事件计 2 分。
