# 月度考核报表使用说明

正式报表以 `中控2026年9月份考核_修复后.xlsx` 为版式和日常填报基准。旧的9月版本、分区临时版和8月参考版已移入 `报表\历史报表`，不作为脚本入口。

## 日期与班组口径

- 每天有两个实际班次，班组按生产排班自动确定。
- 白班记在开始当天；夜班统一记在夜班结束当天。
- 用户输入的是报表第1行看到的日期，以及甲、乙、丙班。
- 如果指定班组当天不上班，脚本提示后退出，不修改报表。

## 常用操作

在项目根目录运行以下命令，也可以双击 `报表\运行报表.bat` 使用菜单。

```powershell
python 报表\report.py update --last
python 报表\report.py update --date 2026-09-03 --team 甲
python 报表\report.py update --from 2026-09-01 --to 2026-09-03
```

普通更新遇到序号0为“是”或“免考”的班次会直接跳过，因此不会覆盖人工修改。成功运行后，序号0写成“是”；只有负数扣分写入表格，没有扣分的项目保持空白。范围更新每完成一个班次就立即保存。

## 班次邮件通知

邮件配置使用项目根目录本机文件 `notification.config.json`，模板见
`notification.config.example.json`。实际收件地址配置不会提交 Git；SMTP 密钥只能
通过环境变量提供：

```powershell
$env:DCS_SMTP_PASSWORD = "<SMTP授权码>"
```

独立发送只读取 Result Package（`result.json` 和 `images/*.png`）：

```powershell
dcs-performance send-email --package .\assessment_reports\<run-id>
dcs-performance send-email --package .\assessment_reports\<run-id> --preview
dcs-performance send-email --package .\assessment_reports\<run-id> --resend
```

也可以在更新报表并成功原子保存后自动发送：

```powershell
python 报表\report.py update --date 2026-09-03 --team 甲 --send-email
```

邮件发送失败不会回滚已保存的 Result Package 或 Excel；命令会返回失败，之后可用
独立命令加 `--resend` 补发。相同 `run_id` 默认只发送一次，`--dry-run` 和
`--preview` 都不会发送邮件或写入成功状态。无扣分班次同样会发送“无扣分”通知。

## 免考

```powershell
python 报表\report.py exempt --date 2026-09-03 --team 甲
```

该命令清空目标班次的全部考核项目，并把序号0改成“免考”。中控和现场统计的班次数只统计状态为“是”的班次，不包含免考。

执行免考前会自动备份当前报表，备份位于报表目录下的 `backups` 文件夹。

如需重新考核，先在报表中手工清空该班次的“免考”状态，再运行普通更新或强制重算。`--force` 也不会覆盖“免考”。

## 强制重算

```powershell
python 报表\report.py update --date 2026-09-03 --team 甲 --force
```

脚本会先明确提示人工修改将被覆盖，确认后备份当前报表；如果原始结果包已经存在，也会同步备份，然后重新生成并覆盖目标班次。备份分别保存在报表目录和原始结果目录下的 `backups` 文件夹。

自动化调用如已在外部完成确认，可追加 `--yes`。

## 新增、修改或停用规则

日常更新不会改变报表结构。规则变更使用：

```powershell
python 报表\report.py sync-rules
```

脚本先预览新增、修改、停用和归属变化，确认后才备份并同步。规则身份使用 `(rule_id, point_id)`，归属使用 `control`、`field`、`shared`，不依赖当前行号。新增规则追加到项目区末尾并复制邻近行样式；停用规则在当月保留原行和历史扣分，只记录停用日期。

规则或点位可在 `config.json` 中设置：

```json
{
  "audience": "control",
  "effective_date": "2026-09-01",
  "inactive_date": null
}
```

点位级设置优先于规则级设置。新增点位未设置归属时默认按中控处理，并在预览中提示。

旧的 `fill_report.py` 已停用，直接运行会拒绝写入，以免绕过“是/免考”保护。`build_report.py` 也已停用直接重建入口；规则刷新旧入口 `refresh_report.py` 只会转交 `report.py sync-rules`。

## 新建下个月报表

```powershell
python 报表\report.py new-month --month 2026-10
```

该命令复制当前正式报表，不从空白重建。它只更新标题、日期、班组、当月列数、规则项目、合计与统计公式，并清空全部状态和扣分。新文件默认生成在 `报表` 目录；如需指定文件名，可追加 `--output 路径.xlsx`。

## 固定布局与保护范围

当前9月正式报表固定为：项目第4～38行，中控合计第39行，现场合计第40行，中控统计第41～44行，现场统计第46～49行。第40行直接使用原空行，不插入行，也不移动下面统计表。跨月或同步规则后，脚本会按表内合计行、映射表和日期列动态识别布局，不再写死为 BM49。

普通更新只写目标班次的序号0状态格和项目结果格，不改 A:E、标题、日期、班组、公式、样式、合并单元格、冻结窗口或隐藏映射表。只有 `sync-rules` 和 `new-month` 可以进行必要的结构调整。
